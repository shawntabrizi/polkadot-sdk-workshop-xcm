# docs

Conceptual material that doesn't fit neatly into a source-file header comment. Everything here is optional reading — you can complete the workshop end-to-end without it — but these notes go deeper than the per-file hints.

## What's here

- [`fundamentals/location.md`](fundamentals/location.md) — the mental model for XCM Locations (filesystem analogy, relative vs absolute, junctions). Worth reading before or alongside Lesson 1.

## Adding a doc

Add one when you have a concept that:

1. spans multiple lesson files (so it doesn't belong in any one header), and
2. is stable enough to be worth writing down (so it doesn't rot with the next SDK bump).

Link new docs from the top-level README's [Lessons](../README.md#lessons) or [Reference](../README.md#reference) sections so they're discoverable.
